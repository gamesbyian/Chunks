# Experience conformity decision cases: practice, not measured agent improvement

Use as public *practice probes*. To establish actual skill improvement, use unseen adapted tasks with baseline and skill-equipped agents, inspecting their code/outputs and independent render/behavior evidence. Fluent rationales alone prove nothing.

| Case | Expected decision | Incorrect shortcut |
|---|---|---|
| A. Internal hash verifier changes no visible state | Mark experience N/A; real hash positive/negative evidence | Mandatory screenshot or visual sign-off |
| B. Priority action in an established transfer row | Reuse canonical row/Details patterns, define controls/states, prove remote/local ID, semantics and render | Invent second priority page or trust RPC success as UI proof |
| C. Navigation test passes but rendered row violates approved compact density | Record function/interaction proof and distinct presentation failure, fix shared layout | Treat screenshot existence as visual approval |
| D. Old screenshot file names an owner-retired wizard | Preserve enduring warning/identity acceptance with current UI evidence | Restore obsolete wizard or delete its sole independent oracle |
| E. Owner-mandated warning color and accessible focus order | Keep normative presentation and accessibility tests | Retire inconvenient visual checks as “brittle” |
| F. Three annotated screens share spacing cause; one has broken Stop | Group spacing once, keep all four observations, separately repair/test Stop | Close all from a single new screenshot |
| G. Exploratory mood-board opposes approved layout | Keep approved design; optionally offer owner design choice | Silently promote a proposal into requirement |
| H. Renderer inaccessible, compilation green | Report presentation unverified with missing evidence | Claim visually accepted from filename |

**Scoring dimensions:** correct authority; smallest coherent intervention; independent functional/interaction/presentation claims; retention of genuine safety/accessibility witnesses; truthful execution status; minimal human/CI burden. Include positive and no-action counterexamples; don't turn this into a universal release gate.
