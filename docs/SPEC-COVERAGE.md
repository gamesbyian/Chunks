# Chunks acceptance and specification coverage

**Purpose:** precise required outcome and evidence gate. This is an **acceptance checklist**, not a PR diary. Consult [WORK-QUEUE](WORK-QUEUE.md) for execution order, [QUALITY-LEDGER](QUALITY-LEDGER.md) for historical receipts, and [SPEC-COVERAGE-HISTORY-2026-11-09.md](SPEC-COVERAGE-HISTORY-2026-11-09.md) for the archived narrative. | One-row fixed footer | Transfers / + Add / Connections / Options, all four in a **single row**, navigable under IME and nested Details | 320/412dp, normal/200% font, screenshot, TalkBack/focus, keyboard and target hit tests |

**Gate rules:** A green unit/mock test is not installed app proof; a remote RPC ACK is not verified transfer/pieces; a red, skipped, cancelled or old-head check cannot qualify a changed PR. Tests must be explicit about source SHA/tree, run ID, artifact digest, test identities and evidence tiers. **Not yet proven by documentation:** owner's new UI/media expectations, latest-main installed APK and separate physical/production/signing tiers. Never silently classify these as accepted.
