# Native Chunks Android screenshot atlas

The manually runnable (and one-time PR test) [native-visual-atlas.yml](../.github/workflows/native-visual-atlas.yml) boots an Android API 35 emulator, installs the real debug APK and captures **actual** `screencap -p` PNG files plus `uiautomator` accessibility hierarchies. Cases: 360x800dp-class small, ~411x914dp standard, 1.4× text, wide ~480x1000dp. Pixel resolution, density, text scale, SHA256 and view identity are recorded in a machine-readable manifest and reviewer checklist. Artifacts expire after 14 days. No server login, passwords, or torrent writes.

Screenshots are evidence, not blanket approvals. The [baseline run 40127924862](https://github.com/gamesbyian/Chunks/actions/runs/40127924862) actually captured four installed-app connection states and accessibility hierarchies at source `368a9ba3c306ced713e8e9a3f3476db8582b0528`. Manual pixel inspection identified white status icons on cream and led to the verified dark-status-icon correction in merged #54. [Native Add run 40127924888](https://github.com/gamesbyian/Chunks/actions/runs/40127924888) captured exact destination review and actionable invalid-path rejection. [Native session Remove run 40128569432](https://github.com/gamesbyian/Chunks/actions/runs/40128569432), source `87a2a7004f4aea21f2f51b147810d532b6d2cf48`, passed Compose semantics and produced a visually inspected real PNG of the exact-hash/name/path confirmation; its capture is a standalone Compose test state, not a screenshot of a server-connected Transfers list.

The [API 35 native Add recovery run 40129567925](https://github.com/gamesbyian/Chunks/actions/runs/40129567925), tested at `d2e845f86b6dace97a73f275aa1ceae4aac4633f`, also captured a real standalone Compose PNG of an uncertain Add with an explicit **Check server state (read only)** action and no repeat Add button. Android/JVM [run 40129567898](https://github.com/gamesbyian/Chunks/actions/runs/40129567898) passed the companion lost-ACK single-write regression. The image was inspected; it does not prove hosted Seedhost readback or the full app-connected journey.

**Still missing:** full Transfers/Places/Organize/Server inventory-driven native atlas using a sanitized actual Seedhost snapshot; long/RTL titles, dense inventories, reconnect/error/uncertain state families, 200% type, TalkBack, physical Pixel 6 Pro acceptance and explicit human visual approval. The existing [real-data QA selector](../tools/seedbox_fixture_qa.py) can pick representative cases only after a real opt-in inventory capture (`inspect_inventory=true`). Synthetic or isolated Compose screenshot evidence must remain labelled separately from real server data.

To run locally with an existing emulator: build `gradle :app:assembleDebug`, install the APK, set `wm size`/`wm density` and `settings put system font_scale`, launch MainActivity, capture `adb exec-out screencap -p` and process with `tools/native_visual_atlas.py`. No fake or HTML-only screenshots count as native acceptance.
