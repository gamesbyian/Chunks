2. **Unified Transfer Details:** Remove in-content Back to transfers and Transfer details heading; combine original release/list name, truthful status, short Local/Wood client origin, identified title/type/year/provenance and format-aware art in **one section directly under wordmark**. Preserve separate **Change list name**, **Edit identification**, **Choose artwork** actions and manual override persistence; remove lower duplicated artwork info section after migration, but not technical media inspection. 3. **Artwork shapes, list compactness:** Use video 2:3 posters, album/audiobook/software 1:1, book/comic 2:3, magazine 3:4 as preferred formats, natural image ratio when actual art differs. Do not stretch/crop into squares or discard manual choices; bounded list thumbnail slots, no row-height explosion. Maintain cached and unidentified states correctly.
4. **Connections root:** Replace separate Connected and Saved servers sections with **one card per stable profile ID**, verified connected first and other saved/attention profiles stable below; concise status, context-specific View transfers/Connect and Manage. Manage owns hostname/endpoint, colour, credentials, folder, Disconnect/Forget and server tools. With zero profiles, compact purple **Connect to a remote client** card and + Add connection **inside**; with one or more, a compact + Add connection action but **no large onboarding card**. Never conflate cached/read-only inventory with mutation-authorized connected state; remember-profile and remember-login differ.
5. **Language + count:** Use **client** throughout user-facing UI instead of **environment** where it means a torrent client; keep user short names (Local, Wood) wherever clearer. Do **not** blindly rename internal `environmentId`, identifiers, saved data, RPC/session security or APIs. The transfer summary should display **`N clients included`** for clients selected into the current view, including selected offline/stale clients without saying they are live. **Inspect the existing `sources excluded` count calculation before changing its label.** Fix the count if actually derived from excluded sources. Preserve truthful "No live rates", stale/unknown and lock states.
6. **Related visual polish already approved earlier in this session:** Keep compact transfer list and existing scoped search/filter/batch, add-source short names and in-place outcome, per-client colour consistency, and Connections/Details/Options labels coherent. Do not regress Add button availability with blank optional remote folder, remote rTorrent starts, real remote folder navigation/new-folder verified capability, or verified Remove-with-data behavior.
