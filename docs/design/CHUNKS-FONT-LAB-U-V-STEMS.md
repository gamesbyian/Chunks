U/u/V/v: sixteen source-only native Bezier master candidates on the isolated font/lab branch. Each glyph has independent 400, 500, 600, 700 inside-join and stroke parameters. U forms use smooth rounded bottom joins, V forms use calibrated internal diagonal joins. Shapes were sampled for source-envelope safety, original contour count, monotonic ink and nonempty interiors. No original reference, 800 weight, Android font or app resources changed. These are neither owner-reviewed artwork nor a refreshed compiled OTF family. The branch now contains 29 source-specific glyphs per lighter weight = 116 editable SVG masters.
