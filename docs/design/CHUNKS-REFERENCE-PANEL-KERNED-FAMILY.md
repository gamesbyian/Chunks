# Chunks Reference Panel Kerned: complete five-weight accented spacing experiment

**Status: independently installable experimental family, not shipping.** The accepted Chunks Regular/Medium/Semibold/Bold/ExtraBold OTFs, branded SVG wordmarks, and packaged Android ExtraBold are immutable in this workstream. This distinct family is named **Chunks Reference Panel Kerned** so that each of its five OTFs can coexist in a font installer with the five accepted fonts and raw experimental accent-study faces.

## What changed

Every weight starts with its existing independently compiled **Chunks Reference Panel AccentStudy** source OTF, retaining the 62 editable reference Basic Latin/digit contours, 243–244 reconstructed precomposed accents, all **856 Unicode mappings**, native GPOS/GSUB/GDEF layout features, original CFF charstrings and *all glyph horizontal metrics*. The only glyph layout change is a new bounded **GPOS PairPos Format 1** lookup, appended to the existing `kern` feature and triggered solely for pairs containing a glyph explicitly reconstructed in that weight's original accent manifest.

The algorithm measures the complete native HarfBuzz pair advance (with optional ligatures disabled for an apples-to-apples two-character comparison) and compares it to the very same font's **unaccented canonical base-letter pair**. Each difference is added as bounded kerning, never by scaling the glyph ink or the source outlines. It evaluates ordinary letters/digits adjacent to accented characters and accented–accented pairs, with no change to ordinary–ordinary or non-Latin letter pairs. Corrections are capped at **±180 font units**, lower than the width of a stroke in this 1000-unit/em font, and omitted if below 2 units. Separate disjoint coverage subtables of up to 12 leading glyphs avoid a single oversize OpenType subtable. No native feature is deleted.

| Property | Result |
|---|---|
| New distinct installable weights | Regular 400, Medium 500, Semibold 600, Bold 700, ExtraBold 800 |
| Unicode coverage | 856 mapped characters, unchanged |
| Reconstructed accented glyphs | 1,216 across all five fonts |
| Pair adjustments | About 88,000 per weight, each bounded |
| Compound pair lookup | 26 small Format 1 subtables per OTF |
| Canonical-context regression | All 1,216 reconstructed accents under 1px residual at 48px in eight sample contexts |
| Glyphs, hmtx, GSUB, GDEF and original GPOS | Unchanged, with only an additional `kern` lookup |
| Normal Latin/number shaping and Hindi | Exact same measured advances as input |
| Collisions | No sampled collisions at 14/24/48/82px, not exhaustive proof |
| ExtraBold metadata | Corrected invalid simultaneous REGULAR and BOLD OS/2 flag in the *new* experimental copy |

## Reproducibility

```bash
python -m pip install -r tools/requirements-chunks-font.txt
for weight in 400 500 600 700 800; do
  python tools/build_reference_accent_kerned.py --weights "$weight"
done
python -m unittest discover -s tests -p test_reference_accent_kerned.py -v
python tools/render_reference_accent_kerned.py
```

The generator writes `assets/fonts/experimental/accent-kerned/ChunksReferencePanel-{Regular,Medium,Semibold,Bold,ExtraBold}-AccentKerned.otf` and an exact input/output SHA-256 manifest. Running weights as separate subprocesses bounds memory use and makes single-weight edits inexpensive; manifests merge partial builds **only when the source and generated font SHA-256 match**. CI rebuilds and tests the entire set, publishes five OTFs, Open Font License, and a specimen rendered directly from the compiled files. It commits generated OTFs only to feature branches, never to `main` through a read-only PR job.

## Why this improves the previous prototype

The previous accent reconstruction gave each accented glyph the same **own** horizontal advance as its base letter, but did not always give it the same kerning in *surrounding text*. [The existing eight-context audit](https://github.com/gamesbyian/Chunks/pull/377) found 1,212 of 1,216 glyphs with a contextual mismatch over 1px, and maximum mismatches around 9–11px at 48px. The new test reduces all eight sampled contexts below 1px across all five fonts. The original five nonaccent reference weight studies and five accepted Chunks faces are untouched, preserving mix-and-match flexibility.

## Still open before production

- Correct or replace the geometric source-derived strokes in weights 400–700 with truly individually designed contours.
- Extend the 62 reference Basic Latin/digit glyph masters to punctuation, remaining Unicode letters, **i/j with removed dots**, and connected or stacking diacritics. This experiment inherits upstream Baloo 2 for characters not generated by the conservative accent builder.
- Human or supervised optical review of actual letter shapes, multilingual text collision stress, long filenames, 200% Android text scaling, TalkBack and small display chips.
- Compare the new family to the full original brand reference and choose a definitive typeface without silently replacing the shipping Android font.

Track this work in [issue #347](https://github.com/gamesbyian/Chunks/issues/347). The **SIL Open Font License 1.1** source license and original Baloo 2 attribution must accompany all redistributed derived OTFs.
