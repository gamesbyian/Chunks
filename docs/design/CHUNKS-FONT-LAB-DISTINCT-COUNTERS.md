Experimental nonshipping glyph designs: B, 8, 6, 9, Q and a. All source-native quadratic/cubic Beziers with individually edited counter sizes for 400, 500, 600 and 700. The B and 8 have two independently positioned counters; the 6/9 have terminal hooks; Q has an integrated tail; a has a joined right stem. Shapes were sampled for area progression, topology and reference bounds. This is an unapproved source-only batch; downstream CFFs are deliberately not refreshed on every glyph commit. The font/lab branch contains 25 source-specific basic glyph designs per lighter weight (100 SVG masters), while the last built OTFs are from the previous 52-master checkpoint. Validate offline before promotion and do not open a PR for each batch. Source test: python -m unittest discover -s tests -p test_font_lab_distinct_counters.py -v. Review 14/24/48/82 px specimens for terminal rhythm, counter size and collisions; owner visual approval remains required. See docs/design/CHUNKS-FONT-LAB-OPERATIONS.md and issue #347.
