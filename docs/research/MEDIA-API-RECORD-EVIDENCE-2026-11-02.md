## Concrete API contracts requiring sample JSON

- **TMDB:** [episode credits](https://developer.themoviedb.org/reference/tv-episode-credits) and [season details](https://developer.themoviedb.org/reference/tv-season-details) expose episode identity plus crew member ID, department and job when present. Do not substitute show-level crew for writer of a particular episode. Requires registered API key and appropriate license/attribution.
- **TVmaze:** [API](https://www.tvmaze.com/api) documents episodes by ID, episode guest crew, and show-level crew separately. The **actual JSON** returned by its official example `GET https://api.tvmaze.com/episodes/1/guestcrew` was retrieved on 2026-11-02: the payload is an **array**; each row contains `person.id` (e.g. 15), `person._links.self.href`, and **`guestCrewType`**, with observed values `Story`, `Teleplay` and `Director`. [TVmaze's own credit policy](https://www.tvmaze.com/faq/16/episode-extras) additionally defines `Writer` as a separate type and maps screenplays to Teleplay. Do not substitute `type` for `guestCrewType`, treat Director as Writer or silently merge Story and Teleplay. [*Soul Mates*, episode 43454](https://www.tvmaze.com/episodes/43454/babylon-5-2x07-soul-mates) links writer Peter David to [TVmaze person **73284**](https://www.tvmaze.com/people/73284/peter-david), whose website credits explicitly show episode S02E07 as Writer. **Its exact episode #43454 JSON has not been captured**; expected `person.id=73284, guestCrewType=Writer` must still be checked as a separate test, never entered as a fabricated sample fixture.
- **Grand Comics Database:** its [own site](https://www.comics.org/) explicitly warns that API URLs are stable but fields/format are currently not. [Hulk #331](https://www.comics.org/issue/42860/) contains multiple story and non-story sections with distinct script, lettering, cover, editing roles. A [2026 issue report](https://github.com/GrandComicsDatabase/gcd-django/issues/710) alleges reprint/localization credit contamination: treat this as a source-quality risk report, **not** proven universal corruption.
- **Metron:** [documented API](https://github.com/Metron-Project/metron/blob/master/api/README.md) requires basic or bearer-token auth, exposes issue/creator/role and GCD ID filters, and supports If-Modified-Since detail fetches. Never assume anonymous public API. Confirm exact live nested credit shape with an authorized token; no token in APK.
- **Wikidata:** [Q1351554](https://www.wikidata.org/wiki/Q1351554) exposes TMDB person ID **156223** (P4985) and GCD creator ID **10447** (P9707). Wikidata also defines [TV Maze person ID P11449](https://www.wikidata.org/wiki/Property:P11449), which explicitly has **incomplete coverage** and sometimes-changing values; the current Peter David Q1351554 item shows **no** P11449 mapping for TVmaze person 73284. Hence **TVmaze 73284 is not independently proven equal to TMDB 156223/GCD 10447** by the existing QID bridge. Obtain a verified TMDB episode-crew ID, or a separately corroborated TVmaze↔QID crosswalk, before asserting cross-media writer identity. Fetch one item's EntityData JSON or MediaWiki API, not an unbounded SPARQL graph query. Verify conflicts and provenance; do not join creator records solely by names.
- **MusicBrainz:** [WS/2](https://musicbrainz.org/doc/MusicBrainz_API) distinguishes artist, recording, release-group, release and work, supports relations and pagination; [release-group semantics](https://musicbrainz.org/doc/Release_Group) distinguish conceptual album from precise edition. Use meaningful User-Agent and <=1 call/second; no all-tracks artist attribution from a compilation's release credit.
- **Open Library:** [low-volume API policy](https://openlibrary.org/developers/api) requests caching and human-directed lookups, 1 req/s default, 3 req/s when properly identified. A novel work, audiobook edition and author must retain separate IDs; do not treat the API as a bulk crawler.

## Acceptance stages

1. Record legal, small **actual JSON** fixtures from the **specific target** TV-episode crew, comic-issue credit and Wikidata entity endpoints. A TVmaze example-episode guestcrew JSON was observed, but is **not** proof that episode 43454 exposes Peter David's ID/Writer role. Record source dates, schema variants, nullable fields, attribution and caching restrictions; website evidence cannot substitute for target API responses.
2. Parse and assert exact source-specific writer role, credited comic story and person ID. Differentiate script from cover/letter columns, base issue from variant/reprint, episode writer from show crew and collection name from actual member inventory.
3. Verify Q1351554 provider ID bridge and negative conflicting QID; pass typed resolved IDs to the pure [offline media relation index](https://github.com/gamesbyian/Chunks/pull/1031/files), **merged in [PR #1031](https://github.com/gamesbyian/Chunks/pull/1031)**, but still not connected to live provider data or a user-facing Similar Transfers feature.
4. Integrate only into the existing consent-aware artwork/media enrichment pipeline, with cache/TTL, source-specific quotas, negative cache, provider errors, locked/offline states and no automatic third-party lookups solely on opening transfer details.
5. Test installed Android devices/API tiers and accessible UX; report false-positive rates and costs, warm index benchmark and real performance. No name inference authorizes physical rename or torrent mutation.

**Status boundary:** A real TVmaze *example* guestcrew JSON response was inspected but has not been committed as a licensed full fixture or wired into code. Target episode, comic API and Wikidata JSON joins, legal clearance and rate/consent gates remain unverified. No provider adapter, external lookup or licensed artwork has been integrated as a result of this research.
