Torrent iconography atlas

Six real clients, their source-backed graphics, the Chunks icon collection, and your preferred visual direction in one browsable gallery. Choose the symbols you like, mark gaps for generation, or leave an agent to decide. Nothing here changes the Chunks UI.

How to read the atlas. “UI mapped” means a real source file maps the graphic to a named UI operation (e.g. qBittorrent’s WebUI or ruTorrent’s sprite CSS). “Source asset” means an upstream named graphic exists, but its current screen placement was not independently established. Android XML vectors are rendered from upstream path data when the browser permits fetching them; otherwise open the source link. Existing Chunks SVGs are drafts, not proof of APK usage. External assets are linked, not copied. Export JSON to preserve selections or pass an asset-generation queue to an agent. Browser storage is best-effort, so export is recommended.
