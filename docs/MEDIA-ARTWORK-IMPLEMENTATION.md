# Media artwork and metadata: implementation status and integration interface

**Status (2026-11-05):** source-level vertical slice implemented in `app/src/main/java/io/github/gamesbyian/chunks/media/` with JVM, Robolectric/Compose and opt-in live-provider tests. **Not yet wired into the primary transfer list, details, navigation or settings hosts**; those files were owned by the concurrent Add/destination campaign. No installed-device, emulator or physical-handset acceptance is claimed. Normative requirements remain in [TRANSFER-ARTWORK](TRANSFER-ARTWORK.md), [SHARED-MEDIA-IDENTITY-AND-SIMILAR-TRANSFERS](SHARED-MEDIA-IDENTITY-AND-SIMILAR-TRANSFERS.md) and [MEDIA-PROVIDER-REGISTRY](MEDIA-PROVIDER-REGISTRY.md); this document records what exists and how hosts consume it.

## What is implemented

| Layer | Source | Behaviour |
| --- | --- | --- |
| Recognition | `MediaRecognizer` (over the shared `MediaNameInterpreter`) | Local *proposal* only: kind, title, year, year range, season/episode/multi-episode, season packs, absolute anime numbering (flagged ambiguous), episode title, comic issue/volume, creator–title split for albums/books/audiobooks, editions (Extended, Director's Cut, Remastered…), file-composition evidence weighted by size, adult markers. Raw name and lossless spans preserved; abstains (`UNKNOWN`/`NONE`) on weak evidence. |
| Outbound privacy | `MediaQuerySanitizer`, `MediaLookupQuery` | Only a sanitized title plus typed year/season/episode/creator can leave the device. Refuses URL schemes, magnets, hashes, base32, long tokens, IPs, host names, paths, e-mail, URL-encoding, passkey/API-key words and adult content; refusal reasons never echo input. |
| Providers | `media/providers/*` | **TVmaze** (TV show search, episode and season refinement; no key; CC BY-SA). **MusicBrainz + Cover Art Archive** (release-group search, 500px front art; UA + ~1 req/s). **Open Library** (work search + Covers API; low volume, `default=false`). **TMDB** (movie/TV; *only* with the user's own v3 key or v4 token, stored with AndroidKeyStore AES-GCM; adult results dropped). **AniList** (GraphQL POST; **off unless the user turns it on**; queried only for TV lookups with local anime evidence — absolute numbering, fansub `[Group]`, Japanese script — or manual searches; adult excluded server- and client-side; romaji/native/synonym aliases). |
| Matching | `MediaCandidateMatcher` | Explainable scores; Unicode/article-insensitive comparison against titles, original titles and provider aliases; a title-before-subtitle match (`Frieren` vs `Frieren: Beyond Journey's End`) is capped below the confidence threshold so it can only be Suggested; numeric mismatch caps similarity (sequels stay distinct); year/creator/episode-title gates. Several works sharing a title without a disambiguator → `NEEDS_REVIEW` (e.g. *The Office* US/UK), never auto-applied. |
| Orchestration | `MediaEnrichmentService` | Consent gate; background lookups only with *Identify automatically* on an unmetered, non-power-saver network; per-provider minimum interval; `Retry-After` cooldown for 429/503; 401/403 pauses a provider until its key changes; tied TV shows disambiguated by asking which one actually has the episode (bounded to 3); metadata from one provider, artwork completed from a later one. Receipts reuse `MediaEnrichmentCachePolicy`: 30-day positive, 3-day negative (1 h for manual searches), 10-minute failures, stale-while-offline display. |
| Artwork | `media/artwork/*` | HTTPS-only per-provider host allow-lists on every redirect hop; 6 MiB cap; magic-byte sniffing (JPEG/PNG/WebP only; SVG/HTML/GIF refused); bounds-only decode before allocation (≤8000 px edge, ≤40 MP, ≥96 px); power-of-two sampling; 384 px square derivative (≤10 % centre crop, otherwise fit over a blurred fill, never stretched); bounded LRU disk cache (48 MiB, digest-only filenames, pins for user choices) and byte-bounded memory cache; negative cache per URL; deterministic role-preferring selection. |
| Assignments | `TransferMediaAssignment`, `FileTransferMediaAssignmentStore` | Keyed by exact environment + infohash (`MediaTransferKey.of(UnifiedTransferKey)`), so the same hash on two servers stays independent. States: Not identified, Automatic, Suggested, Chosen by you, Couldn't identify, Category art chosen by you. A user choice is never overwritten by later lookups. Atomic app-private JSON. |
| Controller | `TransferMediaController`, `ChunksMedia` | Display reads local state only; explicit *Look up*, manual search (results offered, never auto-applied), choose, category art, reset and purge-all. Stores open lazily on background dispatchers (no Compose-time disk or network work). |
| User images | `ArtworkRepository.importLocal`, `TransferMediaController.importUserImage` | Android Photo Picker (no storage permission), bounded read (≤6 MiB), same validation/composition as remote art; only a processed 384 px derivative is kept, pinned across restarts and eviction. Works with online lookup off; highest artwork precedence; never overwritten by lookups; removed only when no other transfer references the identical image. |
| Image links | `UserImageUrlPolicy`, `ArtworkRepository.importFromUrl` | Explicit "Use image link" only: HTTPS on port 443, no credentials, no IP literals or local suffixes (`.local`, `.lan`, `.home.arpa`…), and every resolved address on every redirect hop must be public (loopback, RFC1918, CGNAT, link-local/metadata, ULA and mapped IPv4 are refused). Same byte/pixel validation as device imports; the URL itself is not stored. |
| Detail header and local evidence | `requestPoster`, `TransferMediaSummaryRoute`, `LocalCoverFinder`, `MediaDiagnostics` | Detail headers load the poster/cover role on demand at its original aspect (≤720 px, clamped 1:2–2:1), never for list rows. Recognized editions, episode ranges, season packs, collection ranges and issues are shown as "From name: …". A conventional `cover.jpg`/`folder.jpg`/`front.jpg`/`poster.*` in a transfer's own file list is offered as "Use cover.jpg from this transfer" when the host can read completed local files. It is never read remotely and is applied only on tap. Settings show title-free counts by state, source, images and corrections. |
| Apply to related | `relatedForChoice`, `applyChoiceTo`, panel section | After a user choice, previews other observed transfers with the same recognized title, compatible kind and no conflicting year; the user can exclude each one before applying. Existing user choices are skipped. TV targets keep their own recognized season/episode with series art, and no per-episode network calls are made. Each transfer stays individually reversible. |
| Embedded tags (local evidence) | `inspection/EmbeddedTagReader`, `MediaRecognizer.withEmbeddedTags`, `inspectLocalAudio` | Bounded pure-Kotlin readers for ID3v2.3/2.4 (text + APIC), FLAC (Vorbis comments + PICTURE) and MP4/M4A/M4B `ilst` (including `moov` after `mdat`), over random-access reads of a *completed local* file only. Tag album/artist/year upgrade music/audiobook proposals to HIGH local confidence ("Embedded FLAC tags") and drive the provider query; an embedded front cover is offered as "Use album art from the files". Never reclassifies video/books/software or adult; untrusted text is cleaned and capped; no native decoders. Tested on real ffmpeg-encoded fixtures and a truncation/mutation sweep. |
| Future-arrival rules | `MediaAssignmentRule`, `FileMediaRuleStore`, `saveRuleFrom` | "Use for future ones" after a genuine user choice saves a removable rule (same recognized title, family and compatible year). New transfers with no assignment inherit it with their own season/episode and no network; existing decisions are never overridden; rules are purged with "Clear all". |
| Technical media details | `inspection/MediaTrackInspector`, `ui/MediaTechnicalDetails` | [MEDIA-INSPECTION](MEDIA-INSPECTION.md) header-only inspection of Matroska/WebM (EBML) and MP4/MOV: container, duration, video codec/size, audio codec/channels/rate/language/name, subtitle codec/language. Nothing is read until the user taps Inspect; 4 MiB read budget; no frame decoding; an absent Matroska language is labelled "container default, not verified", `und` as unknown; partial results disclosed. Real ffmpeg multi-track fixtures + truncation/mutation sweep. Host passes a bounded local byte source (no remote reads). |
| Similar Transfers feed | `MediaRelationBridge` | Converts only Automatic/Chosen matches into provider-qualified facets (`tvmaze:show:475`, season/episode, `tmdb:movie:949`) for the existing offline `MediaRelationIndex`; suggestions and equal titles with different provider IDs never relate. |
| UI | `media/ui/*` | `MediaCategoryTile` (17 bundled vector categories, deterministic accents, redundant dp-sized label), `TransferMediaArtwork` (fixed size, decorative semantics), `MediaStateChip`, `MediaMetadataSummary`, `MediaIdentifyPanel` (consent card, suggestions, manual search, built-in art, reset, "Why this result?"), `MediaPrivacySettingsPanel` (consent, automatic, show/download artwork, metered, per-provider toggles with licence text, user key entry, purge). Ready-wired routes: `TransferMediaIdentifyRoute` (includes informed consent dialog and Photo Picker) and `MediaSettingsRoute`. |

Nothing in the media package can rename, move or delete files, edit torrent metainfo, change labels or issue engine/RPC commands.

## Host integration interface (for the transfer list, details and settings owners)

1. Near the top of the Compose tree: `CompositionLocalProvider(LocalTransferMediaController provides ChunksMedia.get(context).controller) { … }`. Without it every component falls back to name-only category art with no I/O.
2. Row or card: `val media by rememberTransferMedia(MediaTransferKey.of(transfer.key), transfer.originalName, fileHints)` then `TransferMediaArtwork(media, 64.dp)` (or `TransferMediaArtworkButton` to open identification). Use the **original torrent name**, not a display alias. `fileHints` may be empty; supply `MediaFileHint(path, size)` from an already-known file list only — never read payload bytes or remote files for this.
3. Details: `TransferMediaSummaryRoute(key, originalName, fileHints, onChange = { openIdentify() })`, and for the sheet/route `TransferMediaIdentifyRoute(key, originalName, fileHints, readLocalFile = …)`. Pass `readLocalFile` / `openLocalFile` only for completed phone-local transfers. (consent dialog, lookup, search, alternates, device image, category art, reset are all inside).
4. Settings (Options): `MediaSettingsRoute()`.
6. Similar Transfers: build `MediaRelationIndex.build(MediaRelationBridge.members(visibleKeysWithAssignments))` from the authorized visible inventory, then render `SimilarTransfersSection(index.similar(key, visible), display = { inventoryRow(it) }, onOpen = { navigateExact(it) })`. It renders nothing when empty, shows an environment accent **plus its name**, specific labels (Also on …, Same series, Nearby episode, Same writer: …), "(n of m)" for partial collections, a cached/stale marker, default five with Show all, and 56 dp merged-semantics rows. Never trigger lookups from it.
5. Privacy lock / locked profiles: hosts must not call `rememberTransferMedia` for redacted rows (pass a placeholder name) and must keep artwork out of notifications and widgets; the adult category already never shows real art.

## Provider constraints (verified 2026-11-05)

TVmaze: CC BY-SA 4.0, credit/link-back and share-alike; ≥20 calls/10 s per IP (Chunks paces 600 ms); images cacheable. MusicBrainz: meaningful User-Agent, ~1 req/s per IP or all requests are declined (Chunks paces 1.1 s); CAA images carry their own rights. Open Library: not a bulk/back-end API; low-volume human-initiated use, identified User-Agent (Chunks paces 1.1 s, small field lists). TMDB: user's own key, noncommercial terms with mandatory attribution; no shared credential is shipped. AniList: free for non-commercial use, no bulk collection/storage-backend use, unofficial-name rule; nominal 90 req/min currently degraded to 30/min (Chunks paces 2.5 s); default off. Attribution text is shown per provider in settings and per match in details. Licensing for any future commercial distribution needs separate review.
