## Source and status rules

The current XML-RPC adapter supports typed confirmed stopped Add, Start/Stop and session-only Erase (no payload deletion request), along with transfer rates, server views and read-only file inspection. The Add screen is a native two-stage submitting flow whose real Seedhost/physical Android behavior remains unverified. The dedicated #15 run separately exercised the same adapter against an actual rTorrent process; this proves only the ephemeral 0.9.8 deployment, **not** authenticated remote seedbox, JSON-RPC, filesystem writes or physical Android behavior.

The build artifacts are **debug-only** and not production-qualified. No production server data was moved, renamed, deleted, copied or modified in these Chunks runs.

Future evidence must record exact source SHA, server/Android build as appropriate, sanitized environment topology, test action, verification result and remaining uncertainty. Test fixture pass means no more than the fixture asserts.
