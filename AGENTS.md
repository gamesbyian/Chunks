Inspect live main, open PR heads/diffs/checks, issues and actual overlapping edits. Follow the [one work queue](docs/WORK-QUEUE.md), [backend-first mandate](docs/BACKEND-FIRST-COMPLETION.md) and [completion scope](docs/COMPLETION-ROADMAP.md). No fixed agent roster; claim a task, serialize shared-file edits, and integrate only qualified work with appropriate independent review. [Dispatch](docs/AGENT-LANES.md), [handoff](docs/NEXT-PUSH-HANDOFF-2026-11-08.md), [index](docs/INDEX.md). Explicit owner decisions and safety constraints govern; use the relevant [PRODUCT](docs/PRODUCT.md), [UX](docs/UX.md), [ARCHITECTURE](docs/ARCHITECTURE.md), [SECURITY](docs/SECURITY.md), [DECISIONS](docs/DECISIONS.md) and feature contracts. The [documentation standard](docs/DOCUMENTATION-STANDARD.md) defines precedence and evidence ownership.

Execute FE-01–20 and A2611-01–09 through [R0](docs/WORK-QUEUE.md#r0-current-ownership-safety-and-arbitration); audits are evidence, not additional queues. Correctness, missing approved capabilities, real-engine proof and release gates precede discretionary UI work. The [visual atlas](docs/VISUAL-SPECIMEN-ATLAS-PLAN.md) is future-only; functional/accessibility fixes remain allowed. No owner PC/Desktop Commander. Use repo and hosted CI. No speculative rewrites, dependency deletion or optimization without measured cause.

Retain reviewed identity through navigation and recreation. One canonical Transfers/Details browser and four-root footer; no competing Add route. [UX reconciliation](docs/NEXT-PUSH-UX-RECONCILIATION-2026-11-09.md), [unified environments](docs/UNIFIED-ENVIRONMENTS.md).
- Exact profile + verified infohash is job identity. Place is an accessible provider/storage root. Display alias, torrent name, backing path and published copy are distinct. Mode switches are non-mutating. Local Device / This device in UI, Local in code, exact ID `local`; clean installs need no old Phone migration.
- Distinguish requested, acknowledged, verified, refused and uncertain; fresh exact readback and no blind retry. Timeout or cancellation after dispatch does not prove no write. Copy/Move transfer jobs only; separately consent to source-job retirement after verified target Add; preserve files. `d.erase` is not payload deletion authority. [Job contract](docs/CROSS-ENGINE-TRANSFER-JOBS.md).
- Require explicit scoped destructive approval, independent proof and no unrelated cleanup; exclusive creation for non-replacing publication/metadata/rollback; explicit reviewed Replace and ordinary exact-path native payload recheck/reuse allowed by [collision policy](docs/LOCAL-TORRENT-COLLISION-POLICY.md) and [file operations](docs/USER-DIRECTED-FILE-OPERATIONS.md). No path escape or shared-payload deletion. Keep unsafe executors disabled.
- Verify transport/tenant/profile, no HTTPS downgrade or numbered-instance substitution. Protect credentials, private source/URI/passkeys and consent. Media/title lookup default ON for new installs, saved OFF respected; per-job choice at Add only when globally enabled. Local default verified Downloads/Chunks Downloads; remote uses its own default. [Connection](docs/SMART-REMOTE-CONNECTION.md), [privacy](docs/TRANSFER-PRIVACY-LOCK.md), [artwork](docs/TRANSFER-ARTWORK.md).
- Preserve accessibility (48dp, 200% fonts, TalkBack/keyboard, redundant status, reduced motion), approved visual sources and truthful pending/offline states. No Compose-time disk/network effects. [Feature experience contract](docs/FEATURE-EXPERIENCE-CONTRACT.md): functional and experience proof separately.

## Evidence and delivery

Apply [real transfer acceptance](docs/REAL-TRANSFER-ACCEPTANCE.md): real .torrent/magnets, actual daemons, peer/piece-verified bytes and installed production paths outrank mocks. Inspect conventional upstream libtorrent/rTorrent and ruTorrent/Transdroid semantics first; [requirements rationality](docs/REQUIREMENTS-RATIONALITY-AUDIT-2026-10-31.md) prevents speculative blockers. Physical Pixel/SAF/TalkBack, emulator, live server and signed release are separate tiers. Do not request owner APK installation as diagnosis; qualify two independent public magnets and bind digest/source before offering.

Owner authorizes scoped real Seedhost primary and numbered instances, including appropriate exact existing-job mutations; preserve unrelated inventory and restrict data deletion to authorized exact fixtures with file-level proof. Trusted-main manual arming only; no protected writes on PR/push, secret exposure or automatic private-tracker operations. Owner-selected private metainfo is permitted in repo; use public licensed fixtures for untrusted CI. [Seedhost boundaries](docs/SEEDHOST-REMOTE-TESTING.md), [fixtures](docs/PUBLIC-TORRENT-FIXTURES.md). Report unavailable dispatch honestly.

Follow [CI policy](docs/CI-POLICY.md), [test architecture](docs/TEST-ARCHITECTURE.md) and [delivery protocol](docs/ENGINEERING-DELIVERY-PROTOCOL.md). Batch drafts; preflight affected tests/fixtures/selectors with KEEP/REWRITE/REPLACE-EVIDENCE/RETIRE/BLOCK. Preserve behavioral negatives and stable ChunksSemantics; no assertion weakening. No reverse main-to-feature PR; reconcile bounded refs, then exact-head checks. Run `tools/pr_acceptance_report.py` for relevant profile; skipped/red/old-head never passes. Share verified APKs only; public APK names contain chunks and SHA-256 receipt. [Build](docs/BUILD.md). Font creation stays on font/lab, no routine font PR/Actions; [font contract](docs/design/CHUNKS-FONT-LAB-OPERATIONS.md). Approved SVG/vector and reference asset rules in [design index](docs/INDEX.md).
